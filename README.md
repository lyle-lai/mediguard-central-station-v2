
# MediGuard CMS - 医疗设备中央监护站系统 (v2.5)

**MediGuard CMS** 是一个高保真的医疗设备中央监护站（Central Monitoring Station）Web 模拟系统。它模拟了现代医院 ICU/OR/ER 等科室的集中监护场景，基于 **床位 (Bed-Centric)** 进行数据组织，支持多设备融合显示、历史全息回顾及复杂的报警管理逻辑。

本项目不依赖真实医疗硬件，内置了符合医学物理特征的 **IoT 信号模拟器**，可产生 ECG、SpO2、Resp、IBP、CO2 等实时波形。

---

## 🌟 核心功能特性

### 1. 以床位为中心的管理 (Bed-Centric Architecture)
系统不再以设备为核心，而是以**物理床位**为核心组织视图：
*   **科室容量管理**: 支持动态调整科室床位数量（4 ~ 100 张）。
*   **空床管理**: 自动渲染空床位卡片，支持点击空床直接办理“患者入科”与“设备绑定”。
*   **床位排序**: 支持“按床号排序”与“有人床位优先”两种排序视图。

### 2. 多视图布局与自适应显示
系统提供三种视图模式，以适应不同的屏幕尺寸和监护密度需求。**混合网格布局 (Hybrid Grid)** 技术确保了长数值（如 `120/80`）和短数值（如 `60`）都能完美展示。

| 模式 | 适用场景 | 卡片高度 | 波形数量 | 参数容量 | 布局特点 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **标准视图 (Standard)** | 日常监护 | `320px` (h-80) | 默认 **3** 条 | **6~8** 个 | **双列混合网格**。长数值（如血压、时间）自动跨列显示，短数值并排显示。 |
| **密集视图 (Compact)** | 多床位概览 | `192px` (h-48) | 默认 **2** 条 | **3~4** 个 | **单列紧凑布局**。仅显示核心生命体征（HR, SpO2, NIBP），字体自动缩小以适应空间。 |
| **大屏模式 (Big Screen)** | 电视墙/投影 | `100%` 自适应 | 全屏自适应 | **8+** 个 | **沉浸式暗黑风格**。去除侧边栏，参数与波形撑满屏幕，支持分页轮播，头部报警呼吸灯效。 |

### 3. 多设备融合 (Multi-Device Fusion)
支持单床位绑定多台设备，解决重症患者同时连接监护仪和呼吸机的场景：
*   **ICU 监护仪**: 侧重循环系统（ECG, SpO2, NIBP）。
*   **呼吸机**: 侧重呼吸力学（Paw 波形, Flow 波形, Ppeak, VTe）。
*   **麻醉机**: 侧重气体监测（CO2 波形, 麻醉气体浓度, MAC）。
*   **自动融合**: 卡片头部显示所有连接设备图标，波形区域自动混合显示来自不同设备的数据流。

### 4. 智能报警与回顾系统
*   **双类报警**: 区分 **生理报警** (红色/黄色，如心率高) 与 **技术报警** (青色，如探头脱落)。
*   **报警快照 (Snapshot)**: 报警触发瞬间，系统自动冻结并保存前后 10 秒的 **全息波形** 和 **参数数值**。
*   **防抖与去重**: 内置 10秒 报警防抖逻辑，避免重复记录同一事件。
*   **历史回顾**: 支持查看报警发生时的“冻结条图”。

### 5. 高级配置能力
*   **全局配置**: 在“系统设置”中定义每种设备的默认显示模板（颜色、顺序、可见性）。
*   **床位级自定义**: 点击卡片上的“设置”图标，可对**特定床位**进行个性化配置（例如：该床位隐藏 ECG II，显示有创血压）。
*   **演示模式 (Demo Mode)**: 内置开关。开启时生成模拟数据；关闭时清空数据，等待真实 API 接入。

### 6. 历史趋势回顾
*   **全息波形 (Full Disclosure)**: 像心电图纸一样横向拖动查看过去时间段的连续波形。
*   **趋势图/表**: 支持 1h / 4h / 8h / 24h 趋势数据分析。

## 🔐 登录与权限体系

系统模拟了基于角色的访问控制 (RBAC) 和科室数据隔离。

| 用户名 | 密码 | 角色 | 权限描述 |
| :--- | :--- | :--- | :--- |
| **admin** | `123` | 系统管理员 | 访问所有科室 (`ALL`)，可修改所有配置，可切换科室视图。 |
| **icu** | `123` | 护士长 | 仅限 **ICU** 科室数据。可管理 ICU 床位。 |
| **or** | `123` | 麻醉医师 | 仅限 **手术室 (OR)** 数据。 |
| **er** | `123` | 急诊医师 | 仅限 **急诊科 (ER)** 数据。 |
| **gen** | `123` | 护士 | 仅限 **普通病房** 数据。 |

> **注意**: 登录特定科室账号后，左侧的“切换科室”菜单将被隐藏，且只能查看本能够接收到的报警信息。

## 🛠 技术栈

*   **Core**: React 18, TypeScript, Vite
*   **Styling**: Tailwind CSS (定制 Medical Dark 主题)
*   **Rendering**: HTML5 Canvas (高性能实时波形绘制, 60fps)
*   **Icons**: Lucide React
*   **State**: React Hooks (useMemo, useEffect for simulation loop)

## 🚀 快速开始

### 1. 启动项目
```bash
npm install
npm run dev
```

### 2. 模拟操作流程
1.  **登录**: 使用 `admin / 123` 登录系统。
2.  **入科**:
    *   点击任意一个 **"空闲床位"** 卡片。
    *   在弹窗中选择一台“在线”的物联网设备，填写患者姓名，点击绑定。
3.  **触发报警**:
    *   进入 **设置 (Settings)** 页面。
    *   点击 **"立即触发测试报警"**，观察大屏的声光报警效果。
4.  **查看详情**:
    *   点击患者卡片进入详情页。
    *   点击 **"历史回顾"** -> **"波形"**，拖动查看历史记录。
5.  **调整布局**:
    *   在顶部导航栏切换 **"标准" / "密集" / "大图"** 模式。
    *   使用 **"排序"** 按钮将有病人的床位排在前面。

---

## ⚠️ 待机与断连模式
*   **待机 (STANDBY)**: 设备处于待机状态时，卡片显示灰色虚线边框，波形区域覆盖 "STANDBY" 字样，不触发报警。
*   **断连 (OFFLINE)**: 模拟网络中断或设备掉电，显示断连状态。
